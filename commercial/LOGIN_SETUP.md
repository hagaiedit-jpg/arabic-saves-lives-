# הפעלת "תוכן מאחורי התחברות" — צעד אחר צעד

> ההחלטה: התוכן ייפתח רק למי שמתחבר (אימייל + קוד חד-פעמי), והגישה מוגבלת לרשימת
> מורשים שאת שולטת בה. הקוד באפליקציה **כבר בנוי**; מה שנשאר הוא הקמה חד-פעמית
> בחשבון ה-Supabase שלך. אני מלווה שורה-אחר-שורה כשתגידי «מתחילים».

## המצב כרגע
- ✅ מסך התחברות (אימייל → קוד) בנוי באפליקציה.
- ✅ קריאות התוכן כבר נושאות את הטוקן של המשתמש — מוכן ל-RLS.
- ✅ נעילת ההתחברות **כבויה** (`window.LOGIN_GATE`), כדי שאף אחד לא ייחסם עד שנסיים את ההקמה.
- ⏳ נשאר: 3 צעדים ב-Supabase, ואז מדליקים.

---

## צעד 1 — להדליק התחברות באימייל (Supabase Auth)
בלוח הבקרה של Supabase → **Authentication → Providers → Email**:
- לוודא ש-Email מופעל.
- להדליק **Email OTP** (קוד חד-פעמי) — כדי שיישלח קוד 6 ספרות ולא רק קישור.
- (מומלץ) לערוך את תבנית המייל לעברית עם שם הערכה.

## צעד 2 — רשימת מורשים (מי מקבל גישה)
טבלה קטנה שרק אימיילים שבתוכה מקבלים תוכן:
```sql
create table if not exists public.members (
  email text primary key,
  added_at timestamptz default now(),
  note text
);
```
להוסיף חייל = שורה אחת (דרך Table Editor או SQL):
```sql
insert into public.members (email, note) values ('soldier@example.com', 'קבוצת וואטסאפ');
```
להסיר גישה = למחוק את השורה.

## צעד 3 — לנעול את טבלת התוכן (RLS) — הלב של ההגנה
```sql
alter table public.phrases enable row level security;

-- קריאה מותרת רק למשתמש מחובר שנמצא ברשימת המורשים:
create policy "members can read" on public.phrases
  for select
  using (
    auth.role() = 'authenticated'
    and lower(auth.jwt() ->> 'email') in (select lower(email) from public.members)
  );
```
> ⚠️ לפני שמריצים RLS — לוודא שהוספת את עצמך ל-`members`, אחרת גם את תיחסמי.
> אם יש עוד טבלאות תוכן (למשל תשובות/מדיה) — נחיל עליהן את אותו היגיון.

## צעד 4 — להדליק את הנעילה באפליקציה
אחרי ש-1–3 עובדים, מדליקים את השער. אפשר בשתי דרכים:
- **לבדיקה מהירה במכשיר שלך:** בקונסולה — `localStorage.setItem('login_gate','1')` ורענון.
- **להשקה לכולם:** אני משנה את ברירת המחדל בקוד ל-ON ודוחפת גרסה.

---

## איך זה נראה לחייל (סטנדרט שוק)
פותח את האפליקציה → «התחברות לערכה» → מזין אימייל → מקבל קוד במייל → מכניס → נכנס.
פעם אחת, ואז זה זוכר אותו. אפשר להתנתק דרך «עוד → מידע ומשפטי → החשבון שלי».

## גדילה מיחידים ליחידות
- היום: מוסיפה אימיילים בודדים (קבוצת הוואטסאפ).
- בהמשך: מוסיפה אימיילים של יחידה שלמה, או נעבור למודל «קוד יחידה» אם יהיה נוח יותר.
- אפשר בכל רגע לראות מי ברשימה ולהסיר גישה.

## מה עוד אפשר להוסיף בהמשך (לא חובה עכשיו)
- כפתור «המשך עם Google» (לחיצה אחת).
- מסך ניהול מורשים בתוך האפליקציה (במקום Table Editor).
- דוא"ל אישור/ברוך הבא אוטומטי.
